# Game Flow

## 1. 캐릭터 선택

- 게임 시작 전 사용할 캐릭터를 선택하고, 캐릭터별 능력치와 해금 상태를 기준으로 선택 가능 여부를 관리합니다.

## 2. 게임 시작

- `GameManager`가 플레이어를 활성화하고 진행 시간과 게임 상태를 초기화합니다.
- `LevelUp.SelectDefaultItem`으로 시작 아이템을 지급한 뒤 스폰, `HUD`, 사운드가 플레이 상태로 전환됩니다.

## 3. 플레이어 이동

- `Player`가 입력 축을 읽어 이동 방향을 계산하고 위치를 갱신합니다.
- `Character`는 선택 캐릭터에 따른 이동 속도와 공격 관련 보정값을 제공합니다.

## 4. 적 스폰

- `Spawner`가 진행 시간에 맞는 스폰 데이터를 선택해 적을 배치합니다.
- 생성된 적과 투사체는 `PoolManager`를 통해 재사용됩니다.

## 5. 자동 공격

- `Scanner`가 주변 적 중 가장 가까운 대상을 갱신합니다.
- `Weapon`은 무기 타입에 따라 근접 회전 공격이나 원거리 발사를 실행하고, `Bullet`은 피해와 관통 흐름을 처리합니다.

## 6. 성장 시스템

- `ItemData`와 `Item`은 보상 아이템 정보와 선택 효과를 관리합니다.
- `LevelUp`은 선택 가능한 보상을 표시하고, `Gear`는 장비 효과를 공격 주기와 이동 속도에 반영합니다.

## 7. 게임 종료

- 생존 성공 또는 사망 조건이 충족되면 `GameManager`가 결과 흐름으로 전환합니다.
- `Result`는 결과 화면을 표시하고, `HUD`는 생존 시간, 처치 수, 체력, 레벨 정보를 갱신합니다.

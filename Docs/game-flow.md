# Game Flow

## 1. 캐릭터 선택

- 게임 시작 전 사용할 캐릭터를 선택합니다.
- 캐릭터별 능력치와 해금 상태를 기준으로 선택 가능 여부를 관리합니다.

## 2. 게임 시작

- `GameManager`가 게임 상태와 진행 시간을 관리합니다.
- 플레이어를 활성화하고 `LevelUp.SelectDefaultItem`을 통해 시작 아이템을 지급합니다.
- 스폰, UI, 사운드 흐름이 게임 시작 상태로 전환됩니다.

## 3. 플레이어 이동

- `Player`가 입력을 받아 이동을 처리합니다.
- `Character` 정보를 기반으로 캐릭터 능력치 보정값을 관리합니다.

## 4. 적 스폰

- `Spawner`가 게임 진행 흐름에 따라 적을 생성합니다.
- `PoolManager`를 통해 오브젝트를 재사용합니다.

## 5. 자동 공격

- `Scanner`가 주변 적을 탐지합니다.
- `Weapon`과 `Bullet`이 공격 처리를 담당합니다.

## 6. 성장 시스템

- `Item`과 `ItemData`를 통해 아이템 정보를 관리합니다.
- `LevelUp`에서 레벨업 보상 선택 흐름을 처리합니다.
- `Gear`는 장비 효과를 무기 공격 주기와 플레이어 이동 속도에 반영합니다.

## 7. 게임 종료

- `Result`에서 생존 성공 또는 사망 결과를 표시합니다.
- 생존 시간, 처치 수, 체력, 레벨 정보는 `GameManager`와 `HUD` 흐름에서 관리됩니다.

# Game Flow

## 1. 게임 시작

- `GameManager`가 게임 상태와 진행 시간을 관리한다.
- 플레이어, 스폰, UI 흐름이 초기화된다.

## 2. 플레이어 이동

- `Player`가 입력을 받아 이동을 처리한다.
- `Character` 정보를 기반으로 캐릭터 상태를 관리한다.

## 3. 적 스폰

- `Spawner`가 게임 진행 흐름에 따라 적을 생성한다.
- `PoolManager`를 통해 오브젝트를 재사용한다.

## 4. 자동 공격

- `Scanner`가 주변 적을 탐지한다.
- `Weapon`과 `Bullet`이 공격 처리를 담당한다.

## 5. 성장 시스템

- `Item`과 `ItemData`를 통해 아이템 정보를 관리한다.
- `LevelUp`에서 레벨업 보상 선택 흐름을 처리한다.

## 6. 게임 종료

- `Result`에서 생존 시간, 처치 수, 보상 정보를 표시한다.

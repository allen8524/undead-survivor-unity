# Game Flow

이 문서는 Undead Survivor의 주요 플레이 흐름을 정리한 문서입니다.

게임은 캐릭터 선택에서 시작해 전투, 레벨업, 생존 성공 또는 사망 결과 화면으로 이어집니다.

## 1. 캐릭터 선택

- 게임 시작 전 사용할 캐릭터를 선택합니다.
- 캐릭터별 능력치와 해금 상태를 기준으로 선택 가능 여부를 관리합니다.
- 선택된 캐릭터 정보는 게임 시작 시 `GameManager`와 `Character` 흐름에 반영됩니다.

## 2. 게임 시작

- `GameManager`가 플레이어를 활성화하고 진행 시간과 게임 상태를 초기화합니다.
- `LevelUp.SelectDefaultItem`을 통해 시작 아이템을 지급합니다.
- HUD, 스폰 시스템, 사운드가 플레이 상태로 전환됩니다.
- `Time.timeScale`을 1로 되돌려 게임을 진행 상태로 만듭니다.

## 3. 플레이어 이동

- `Player`가 입력 축을 읽어 이동 방향을 계산합니다.
- `Rigidbody2D.MovePosition`으로 실제 위치를 갱신합니다.
- `Character`는 선택 캐릭터에 따른 이동 속도와 공격 관련 보정값을 제공합니다.
- 플레이어 방향에 따라 스프라이트와 손 위치가 보정됩니다.

## 4. 적 스폰

- `Spawner`가 진행 시간에 맞는 `SpawnData`를 선택합니다.
- 선택된 스폰 데이터에 따라 적의 체력, 이동 속도, 스폰 주기가 결정됩니다.
- 스폰 포인트 중 하나를 선택해 적을 배치합니다.
- 생성된 적은 `PoolManager`를 통해 재사용됩니다.

## 5. 자동 공격

- `Scanner`가 주변 적 중 가장 가까운 대상을 갱신합니다.
- `Weapon`은 무기 타입에 따라 근접 회전 공격 또는 원거리 발사를 실행합니다.
- `Bullet`은 피해량, 관통 횟수, 비활성화 흐름을 처리합니다.
- 플레이어는 이동에 집중하고 공격은 자동으로 처리되도록 구성했습니다.

## 6. 적 피격 및 처치

- `Enemy`는 투사체와 충돌하면 피해를 받습니다.
- 체력이 남아 있으면 피격 애니메이션과 넉백을 처리합니다.
- 체력이 0 이하가 되면 사망 상태로 전환됩니다.
- 적 처치 시 처치 수가 증가하고 경험치가 지급됩니다.

## 7. 성장 시스템

- 경험치가 기준치에 도달하면 레벨이 증가합니다.
- `LevelUp`은 선택 가능한 보상 후보를 표시합니다.
- `ItemData`와 `Item`은 보상 아이템 정보와 선택 효과를 관리합니다.
- `Gear`는 장비 효과를 공격 주기와 이동 속도에 반영합니다.
- 레벨업 선택 중에는 게임 진행을 멈추고, 선택 후 다시 진행합니다.

## 8. 게임 종료

- 제한 시간 동안 생존하면 생존 성공 흐름으로 전환됩니다.
- 체력이 0 이하가 되면 사망 흐름으로 전환됩니다.
- `Result`는 생존 성공 또는 사망 결과 화면을 표시합니다.
- `AudioManager`는 결과에 맞는 배경음과 효과음을 처리합니다.

## 9. 결과 확인 및 재시도

- 결과 화면에서 생존 여부와 플레이 결과를 확인합니다.
- 재시도 시 현재 씬을 다시 로드합니다.
- 종료 버튼을 통해 앱을 종료할 수 있습니다.

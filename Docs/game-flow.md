# Game Flow

## 1. 시작 흐름

1. 시작 화면에서 캐릭터를 선택한다.
2. `GameManager.GameStart()`가 호출되며 플레이어 정보와 체력이 초기화된다.
3. 플레이어 오브젝트와 UI가 활성화되고 BGM이 재생된다.
4. `isLive`가 true로 바뀌면서 게임 시간이 진행된다.

## 2. 플레이어 흐름

1. `Player`가 입력 벡터를 받아 Rigidbody2D 기반으로 이동한다.
2. 이동 방향에 따라 Animator 파라미터와 SpriteRenderer 방향을 갱신한다.
3. 적과 접촉하면 체력이 감소한다.
4. 체력이 0 이하가 되면 `GameManager.GameOver()`가 호출된다.

## 3. 적 스폰 흐름

1. `Spawner`가 게임 시간을 기준으로 스폰 데이터를 선택한다.
2. 플레이어 주변 위치에 적을 배치한다.
3. `PoolManager`에서 비활성화된 적 오브젝트를 재사용한다.
4. 적은 플레이어를 추적하고, Bullet 또는 Weapon과 충돌하면 피해를 받는다.

## 4. 전투 흐름

1. `Scanner`가 주변 적을 탐지한다.
2. `Weapon`은 무기 타입에 따라 근접 회전 공격 또는 원거리 투사체 공격을 실행한다.
3. `Bullet`은 적에게 피해를 주고 관통 수치가 소진되면 비활성화된다.
4. 적이 사망하면 처치 수와 경험치가 증가한다.

## 5. 성장 흐름

1. 경험치가 다음 레벨 조건에 도달하면 레벨이 오른다.
2. `LevelUp` UI가 열리고 게임 시간이 일시정지된다.
3. 플레이어는 무기, 장비, 회복 아이템 중 하나를 선택한다.
4. 선택한 아이템에 따라 신규 무기 생성, 무기 강화, 장비 효과 적용, 체력 회복이 처리된다.

## 6. 종료 흐름

1. 제한 시간까지 생존하면 `GameVictory()`가 호출된다.
2. 체력이 0 이하가 되면 `GameOver()`가 호출된다.
3. `Result` UI가 활성화되고 승리 또는 패배 화면이 표시된다.
4. 다시 시작 또는 종료 버튼으로 게임을 재진행하거나 앱을 종료할 수 있다.
